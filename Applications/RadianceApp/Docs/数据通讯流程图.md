# 图2 数据通讯流程图

医学影像三维重建软件（Vision Magic Ecosystem）采用**单机本地**架构，数据通讯均在用户工作站内完成。

## 流程说明

1. **本地数据源**：用户从本地磁盘选择 DICOM 文件夹、影像文件或已保存场景（`.mrml`/`.mrb`）。
2. **身份鉴别**：启动时通过 `UserManager` / 登录界面校验账户，与本地 `users.db` 交互。
3. **数据导入**：DICOM 模块或【添加数据】读入文件，经 `VolumeImportValidator` 校验后进入 MRML 场景。
4. **内存处理**：在内存中进行 2D/3D 浏览、分割、标注、测量与三维重建。
5. **本地存储**：处理结果、DICOM 索引、审计日志及用户库均写入本机目录。
6. **审计日志**：`AppLogger` 记录启动/退出与用户操作。

## 与旧版差异

- 不再以局域网 PACS / `storescu` 网络传输为主路径。
- 不包含硬件 Ping、针道设备通讯等外部设备数据流。
